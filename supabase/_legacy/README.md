# Legacy SQL Files

Các file này là schema cũ, KHÔNG còn là nguồn sự thật.
Nguồn sự thật hiện tại: `supabase/migrations/` (Supabase CLI).

- `supabase-schema.sql` — schema ban đầu (CREATE TABLE cơ bản)
- `supabase-migration-relational.sql` — patch migration cũ

Giữ lại để tham khảo lịch sử schema. Không dùng để deploy.
